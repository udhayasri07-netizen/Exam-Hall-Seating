Project Description: Exam Hall Seating Allocator
The Exam Hall Seating Allocator is a Java-based desktop application developed using JavaFX to simplify the process of allocating seats to students during examinations. The main objective of this project is to organize student details and assign seats according to the available examination hall capacity.

The application allows users to enter student details, including register number and student name, along with the examination hall name and its seating capacity. The Add Student feature stores student information in a table, while the Allocate Seats feature assigns seats to students based on their order in the table. Each student is allocated a seat number, such as A1, A2, A3, and so on. The application also checks whether the number of students exceeds the specified hall capacity.

The system displays student details in a table containing register number, name, hall name, and seat number. It provides alert messages to notify users about missing information, successful student addition, and capacity-related issues.

Java is used to implement the application logic, while JavaFX provides the graphical user interface, including text fields, buttons, tables, and alert boxes. The TableView component displays student information in an organized format, and event handling enables users to perform operations through the interface.

This project helps reduce manual effort in examination seating arrangements and improves the organization of student records. It also demonstrates the practical application of object-oriented programming, graphical user interface development, event handling, and table-based data presentation.

Conclusion: The Exam Hall Seating Allocator provides a simple and user-friendly approach to managing examination seating arrangements. It helps organize student details, allocate seats according to hall capacity, and display the allocation results clearly. It serves as a useful mini project for understanding JavaFX application development and basic examination management systems.
